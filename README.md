# DJI Action 摄影工作站

这是一个面向 DJI Action 创作者的独立拍摄灵感与规划工具。它将作品参考、参数推演、预览模拟和外拍准备整合在一个网页中，适合在拍摄前整理思路和计划。

## 功能

- **灵感作品库**：浏览、搜索和筛选拍摄方案，查看机位与参数参考，也可复制参数或加入分镜计划。
- **参数实验室**：根据场景尝试曝光、防抖、视角、色彩和 ND 滤镜等参数，并查看取景画面的模拟效果。
- **玩法图鉴**：查阅人像、风光、运动等题材的机位与拍摄建议。
- **外拍分镜计划**：编排分镜、时间段、机位和拍摄参数，核对器材清单，并导出 CSV 通告单。
- **数据管理**：在浏览器中保存作品、计划和器材清单；支持 JSON 备份与导入。

## 获取与使用

本仓库提供的 ZIP 上传包：[`DJI_Action_摄影工作站.zip`](./DJI_Action_摄影工作站.zip)。解压后打开 `dji-action-photo-lab/index.html`，即可在现代浏览器中使用，无需安装软件或启动后端服务。

## 说明

这是独立的拍摄规划工具，并非 DJI 官方产品。取景器和参数效果为页面内的模拟预览，不会连接或控制真实相机。用户数据保存在当前浏览器中；示例作品图片使用在线素材，查看图片需要联网。
